# Machine Learning and Data Analysis Projects

This repository contains four beginner-to-intermediate machine learning and data analysis notebooks prepared for GitHub presentation while keeping the original project code style and workflow.

## Projects Included

### 1. Titanic Survival Prediction and Exploratory Analysis
- Cleaned passenger data by handling missing values and encoding categorical variables
- Selected relevant features for modeling
- Visualized relationships using a correlation heatmap
- Trained and evaluated Logistic Regression and multiple SVM models
- Best saved result: **about 80% test accuracy**

### 2. Lung Cancer Prediction using Logistic Regression
- Built a binary classification workflow using demographic and health-related survey features
- Encoded categorical variables and selected model inputs
- Split the dataset into training and testing sets
- Evaluated the model using accuracy, confusion matrix, and classification report
- Saved result: **about 96.8% test accuracy**

### 3. Salary Prediction with Linear Regression
- Explored the relationship between years of experience and salary
- Used descriptive statistics, correlation analysis, and scatter plotting
- Built a Linear Regression model and evaluated it with regression metrics
- Saved results: **R² ≈ 0.988** and **MAE ≈ 2446**

### 4. Breast Cancer Diagnosis Classification and Clustering
- Removed non-informative columns and encoded the diagnosis label
- Standardized features before applying machine learning models
- Used K-Means clustering for unsupervised grouping
- Compared Logistic Regression and SVM models for classification
- Best saved result: **Logistic Regression accuracy ≈ 97.4%**
